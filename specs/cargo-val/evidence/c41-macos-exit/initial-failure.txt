The first focused native run had one passing held-child event test and one failing late-registration race control. The exact failure was `already-exited pid is registered: 3`, where errno 3 is ESRCH. This run showed that kqueue rejected EVFILT_PROC registration for a child already in zombie state. The watch path now handles ESRCH by calling waitpid(WNOHANG); if it returns the exited child, the adapter preserves that status as a one-shot pending terminal record. The rerun reported 2 passed, 0 failed.
